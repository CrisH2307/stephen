# Injection coverage per untrusted source (R9)

Part of #10. Every source of third-party text, with where it enters the code, what marks it untrusted, the tests that
exist, and the gap. Each row was checked by reading the code at the file:line given. "Not found" means no code or
test was found for that item. Rules this doc relies on are in `docs/SYSTEM-DESIGN-STEPHEN.md` sections 4.1, 4.6,
4.13 and 4.15, and in `docs/ADR-007-conversation-store.md` and `docs/ADR-014-incident-agent.md`.

Tests named "eval" are `inject` cases in `src/eval/cases.ts`. They run the real model, so they are not part of CI.

## Summary

- **Covered in CI, no protection gap:** Gmail, Notion, Canvas announcements, memory proposals, job task
  from the wake word or phone (L1).
- **Covered in CI except gap W1:** web page text (snapshot, read_text, find), tab titles, page titles, dialog
  text. W1 applies to all of them, since they share one wrapper. The screenshot result URL gap (M1) is fixed (#353).
- **Coverage gaps (protection exists, no test in CI or eval only):** calendar and Canvas framing (tests added with R9),
  tab titles, page titles and dialog text (tests added with R9), YouTube (no eval case), Canvas inbox and due (no
  eval case).
- **Real protection gaps (a test shows the gap, it.fails):** W1 (lookalike closing tags in web text, which every web
  source shares). Fixed: R1 (resume quote escapes `<untrusted_`, #348), M1 (the screenshot page URL is inside the
  untrusted block, #353).
- **Fixed in #364:** J2 (`stephen jobs show` prints the job summary inside `<untrusted_job_output>`) and L2 (an edited
  job's prompt says the earlier job's files are data). Tests: `test/injection/job-frames.test.ts`.
- **Not built yet:** incident issue text (ADR-014 phase 2), job output frame (needed once output or files reach a
  model), untrusted memory origins (only needed when they exist).

## Fixes to make (not in CI)

Each fix changes code under `src/` and needs `[DEV REVIEW]` and an independent review.

1. **W1, lookalike brackets in web text.** File: `src/safety/index.ts` (`DELIMITER_RE` at line 43, `wrapUntrusted`
   at lines 50-60). Proposed fix: map every bracket lookalike to ASCII before the escape, using the Unicode confusables
   data for `<` and `>`, not a fixed list. NFKC alone is not enough: it folds fullwidth `＜` and small `﹤` to `<`, but
   leaves `〈` (U+3008), `‹` (U+2039), `⟨` (U+27E8) and `❬` (U+276C) as they are. The list in the test is a sample, so
   the fix must not stop there. The same fix must also cover a fullwidth solidus (`／`, U+FF0F) and fullwidth letters in
   `untrusted_web_content`: the tag match is ASCII only (tests `gap W1b`). Affects every web-wrapped source (page text, titles, dialogs, YouTube, desktop). Test to
   flip: `test/injection/web-text.test.ts` ("gap W1"), from `it.fails` to `it`.
2. **R1, untrusted_ tag in resume quotes. FIXED in #348.** File: `src/history/resume.ts` (`oneLine` at lines 53-62). Proposed fix:
   in `oneLine`, escape `<` followed by an optional `/` and `untrusted_` as `‹$1untrusted_`. That is the pattern of
   `accounts/result.ts:111` and `jobs/spec.ts:302`. Test to flip: `test/injection/resume.test.ts` ("gap R1"), from
   `it.fails` to `it`; it asserts that no `<untrusted_` or `</untrusted_` survives.
3. **M1, page URL in the screenshot result. FIXED in #353.** File: `src/server/tools.ts` (the screenshot result text at line 631).
   Proposed fix: move the URL inside a `wrapUntrusted` block, or print only the reduced URL (`reduceUrl`, as the private
   tab line does). Test to flip: `test/injection/web-text.test.ts` ("gap M1"), from `it.fails` to `it`.
4. **L2, files of an edited job. Fixed in #364.** Files: `src/jobs/manager.ts` (edit branch at lines 392-405, worktree cut at 527-531,
   folder copy at 535-560), `src/jobs/spec.ts` (`framedTask`, `jobPersona`). Proposed fix: in the new job's prompt, mark
   the copied or branch files as earlier work that may hold third-party text, and state in the dialog that the edited
   job starts from the old job's output. Or start a clean folder and carry only the owner's words. Test to add:
   `it.todo` "gap L2" in `test/injection/planned.test.ts`, then a real test.
5. **J2, job summary printed by the CLI. Fixed in #364.** File: `src/jobs/cli.ts:121`. Proposed fix: wrap the printed summary in
   `wrapUntrusted`, or make the command output owner-only and say so in its help text, so an agent cannot read it as a
   tool result. Needs `[DEV REVIEW]`.

Documentation fix (no code): `docs/SYSTEM-DESIGN-STEPHEN.md` sections 4.13 and 5 say job output is framed as
`<untrusted_job_output>`. The code does not frame it. Either build the frame (when output or files reach a model, see
L2) or change the doc to say output never reaches a model prompt. That second option is not true for edited jobs, so
L2 must be fixed first.
