Get the beta

Setup is a few Terminal commands and three Mac permission clicks. Cris will help you with the first one.

What you need

  • A Mac with Apple silicon (M1 or newer) and macOS 14 or newer. No Intel Macs.
  • Node.js 22 or 24.
  • Claude Code, signed in. Stephen runs on your own Claude plan.
  • Zen or Google Chrome. For your own signed-in Chrome, version 144 or newer.

Install

Run these one at a time:

git clone https://github.com/CrisH2307/stephen.git
cd stephen
npm install
npm run build
npm link
stephen setup

Setup checks your Mac, builds the Stephen Helper app, and creates the "Zen for Stephen" app. Then turn on "Stephen Helper" for Microphone, Input Monitoring and Accessibility in System Settings, Privacy & Security. Setup never asks for a password or a key. If something is wrong, it says what to do, and you can run it again.

Your first command

Hold F5 and say: what time is it.

Update

stephen update

Good to know

  • The app is not notarized by Apple yet. After an update, macOS may ask for permission again.
  • "Hey Stephen" is slower than holding F5.
  • While Zen runs for Stephen, other programs on your Mac can reach its control port. Quit Zen when you are not using Stephen.

Something wrong?

  • Run stephen doctor. It tells you what is wrong with your setup.
  • After a crash, run stephen report. It shows you the file and sends nothing until you type y.
  • Anything else: open an issue on GitHub. Issues are public, so do not paste private text. For a security problem, use the private link on that page.
