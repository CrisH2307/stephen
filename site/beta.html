Get the beta

Stephen is in a friends beta. Setup is a few Terminal steps. Cris will help you with the first one.

What you need

  • A Mac with Apple silicon (M1 or newer) and macOS 14 (Sonoma) or newer. The beta is Apple silicon only.
  • Node.js 22 or 24.
  • Claude Code, installed and signed in. Stephen runs on your own Claude plan.
  • Zen or Google Chrome. One is enough. For your own signed-in Chrome, it must be version 144 or newer.
  • Apple's command line tools. If they are missing, setup tells you the one command to run.

Install

git clone https://github.com/CrisH2307/stephen.git && cd stephen && npm install && npm run build && npm link
stephen setup

If something is wrong, setup stops and says what to do. You can run it again safely. Setup never asks for a password or a key.

What setup does

  1. Checks Node and Claude Code.
  2. Registers Stephen with Claude Code.
  3. Creates the "Zen for Stephen" app. Drag it to your Dock.
  4. Builds the Stephen Helper app.
  5. Runs stephen doctor.
  6. Lists three Mac permissions: Microphone, Input Monitoring and Accessibility. Turn on "Stephen Helper" for each in System Settings, Privacy & Security.

Your first command

Hold F5 and say: what time is it.

Update

stephen update

It needs a clean folder. It tells you if Input Monitoring must be clicked again.

Rough edges

  • The app is not signed yet. After an update, macOS may ask for permission again.
  • "Hey Stephen" is slower than F5.
  • Open Zen with the "Zen for Stephen" app. While it runs, other programs on your Mac can reach its control port. Quit Zen when you are not using Stephen.

Report a problem

  • Run stephen doctor first. It tells you what is wrong with your setup.
  • After a crash, run stephen report. It shows you the file and sends nothing until you read it and type y.
  • Other problems: open an issue on GitHub. Issues are public, so do not paste private text.
  • Security problems: use the private "Security problem" link on that same page.
